Open-source tools

Free tools for researchers and teachers, all under the MIT license. Everything runs on your own computer or in your own browser: no account, no tracking, no server.

VanoAtlas

A local research workspace: projects, tasks, meetings, daily routine, notes, papers and LaTeX in one private app.

macOS · Windows · Linux · MIT

VanoLeaf

A LaTeX editor in the spirit of Overleaf that runs on your own computer: file tree, PDF preview, click-to-jump, offline, and no compile timeout.

macOS · Windows · Linux · MIT

Source on GitHubDownload

VanoLib Reader

A PDF reader for papers in the browser: click a citation to see the reference, preview figures in place, highlight, annotate and cite in five styles.

Chrome · Edge · Brave · MIT

Source on GitHubDownload

VanoNote

A handwritten notebook and classroom whiteboard: pen tablets, PDF annotation, a blackboard mode and a live link for students.

macOS · Windows · Linux · MIT

Source on GitHubDownload

VanoShelf

Order for the Overleaf projects page: sort projects into fields, hide the ones you do not want on screen, blur titles in a shared office.

Chrome · Edge · Brave · MIT

Source on GitHubDownload

VanoVeil

A private corner inside Chrome: a password-protected link bar, a hidden workspace for tabs and a one-key privacy veil.
