# Contributed sections

Each file here is a section written by a reader for an existing guide. `scripts/build.py` inserts it into the guide named in its `guide:` field, after the section named in `after:`, with the name of its author.

See [CONTRIBUTING.md](../../CONTRIBUTING.md#add-a-section-to-an-existing-guide) for the format, or use the [contribution page](https://yassine-aitmohamed.github.io/vanoforum/contribute.html).
